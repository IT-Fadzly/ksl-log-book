How to connect (one time, ~3 minutes)

  1. 1Open your sheet, then Extensions → Apps Script.
  2. 2Delete the sample code, paste everything from apps-script/Code.gs in this project, and Save.
  3. 3Click Deploy → New deployment → Web app. Execute as Me, access Anyone. Authorise when asked.
  4. 4Copy the /exec URL, paste it in the box above, and press Save & test. A test row appears in the sheet.
Access "Anyone" means anyone with the URL can post rows. For internal use keep the URL private, or set a SECRET in Code.gs and in the field below.
